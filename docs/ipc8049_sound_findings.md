# QL IPC sound: what the real firmware does

Ground truth obtained by running the IPC (Intel 8049) firmware in `ipc8049_sim.py` and sending it initiate-sound
commands. Everything below is a measurement of that run, not of a real QL. Tables are regenerated by
`ipc8049_experiments.py`.

## Summary

- **Pitch.** Each half-cycle lasts N timer ticks plus a fixed overhead, where N is the IPC pitch byte (0 means 256)
  and a tick is about 43.6 us (11 MHz / 15 / 32). With duration 0 and no sweep the overhead is about 7.75 ticks,
  which reproduces the published empirical fit to within about 1%. **A non-zero duration adds work to every timer
  interrupt** (overhead about 9.5 ticks), so a timed beep sounds lower than an untimed one at the same pitch.
- **Duration** is a 16-bit unsigned count compared against an accumulator that the timer interrupt advances by
  (pitch count + overhead). The time per unit therefore depends on the pitch (about 46 us at the bottom of the range
  to about 67 us at the top), not a constant 72 us, and expiry is only noticed at half-cycle boundaries. Duration 0
  means no duration check. Values near 65535 can step over the target and never end, depending on the pitch, so
  BEEP -1 is in practice "until cancelled".
- **Sweep.** Positive step starts at pitch1 and negative step starts at pitch2. Once per interval the pitch moves by the
  signed step. The sweep continues while the pitch is strictly between pitch1 and pitch2. Outside that (or on
  reaching either end exactly) the wrap nibble decides: 0 reverses direction at once; 1 to 14 restarts from the
  start pitch that many times and then reverses; 15 restarts forever. The overshooting value is played for one
  interval when reversing, but is replaced by the restart pitch when wrapping.
- **Pitch2 on its own does not mean "no sweep".** With a non-zero step and interval, equal pitches or pitch2 below
  pitch1 give a two-note trill between pitch1 and pitch1 plus step. Step 0 gives a steady tone.
- **Interval 0 is not "no sweep".** The pitch steps on every half-cycle.
- The interval unit is also not 72 us (about 44.5 us at pitches near 20 to 32 with duration 0).

## Assumptions and limits

- ROM: rebuilt from the annotated listing, whose version is not stated (it ends before the version bytes). The binary
  1.2 ROM can be passed instead. Per the download's notes only the keyboard debounce differs from 0.7.
- 11.000 MHz crystal, 15 clocks per machine cycle, timer prescaler /32 cleared by STRT T. Section 6 shows the
  sensitivity: not clearing it at all changes the top pitch by about 3%.
- The ZX8302 link is replaced by a nibble queue; keyboard and serial pins idle. Randomness and fuzziness were not
  explored. The first edge comes up to about one idle-timer period (about 11 ms) after the command.
- The opcode table was checked against the listing (1,575 of 1,576 lines agree; the other is the listing's own
  name for `INS A,BUS`), and the pitch results agree with the published fit. Neither is a substitute for
  measuring a real QL.

## 7. The half-cycle model (what `ipc_sound_vectors.h` checks)

One timer interrupt per half-cycle; each toggles the speaker. State: `pitchx`, `step` (signed 4-bit), `wrap_count`,
`int_acc`, `dur_acc` (both 16-bit, zeroed when the sound starts; `pitchx` starts at pitch1 for step >= 0, else pitch2).
At the end of a half-cycle that was loaded with count `c` (`c' = c`, but 255 if `c` is 0):

1. If duration != 0: `dur_acc += c' + 6` (16-bit, wraps); if `dur_acc >= duration` (unsigned) the sound is flagged to stop.
2. `int_acc += c' + (duration != 0 ? 6 : 4)` (16-bit, wraps).
3. If `int_acc >= interval` (always true when interval is 0): `int_acc = 0`; `pitchx += step` (8-bit);
   if not `pitch1 < pitchx < pitch2`: when `wrap == 15`, or `wrap != 0` and `wrap_count < wrap`, then
   `wrap_count++` and `pitchx = (step >= 0 ? pitch1 : pitch2)`; otherwise `wrap_count = 0` and `step = -step`
   (4-bit two's complement, so by my reading a step of -8 never reverses; not tested).
4. The next half-cycle lasts `(pitchx == 0 ? 256 : pitchx)` ticks of 32 machine cycles, plus the cost of the
   interrupt path that follows, in machine cycles (1 cycle = 15/11 us):

| path | duration 0 | duration != 0 |
|---|---|---|
| no step due | 130 | 185 |
| step, pitch in range | 226 | 281 |
| step, reverse | about 248 | about 317 |
| step, wrap restart | about 252 | |
| duration expires | | about 205 |

Occasional paths run up to 14 cycles longer. The sound-on flag (status bit 1) clears when the main loop notices the
stop flag, which is within about one half-cycle of expiry.
